Catalogue Directory

An open list of music catalogues: musicians and labels publishing their own records from their own websites, which any player, radio or app can read. Nobody approves entries and nobody owns the list. Anyone can copy it and run their own.

Add a catalogue

Give the address of a site that publishes a catalogue. It's checked straight away, and if it works and is shared with other sites, it's listed within the hour. There's no account and no approval.

This copy of the directory doesn't take submissions itself. Submit to any directory that does: the lists are shared, so it will reach this one too.

How it works

Listing is mechanical. A catalogue is listed if its address serves a working catalogue that other sites are allowed to read. Every listed catalogue is checked daily. One its owner makes private disappears at the next check, and one that stays broken for a week is dropped.

The whole list is one file, directory.json, free for anyone to download, use or republish. Apps can read it directly, and software can announce a new catalogue by calling /ping?url=….

Anyone can run a copy. Copy this directory's code and switch on its scheduled updates, and you have a directory of your own. Directories read each other's lists, so a catalogue added to one reaches the others, and none of them can remove it from the rest.
